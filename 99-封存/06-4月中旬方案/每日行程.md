## Day 2 ── 4/15（四）大阪城＋御座船＋造幣局桜の通り抜け｜地鐵

| 時段 | 行程 | 備註 |
|------|------|------|
| 09:00 | 飯店出發 → **長堀鶴見緑地線** 心齋橋站 → 森ノ宮站（直達約 10 分） | 森ノ宮站有電梯 |
| 09:30 | **大阪城公園** 散步（4 月中旬染井吉野櫻已落，但新綠＋晚櫻品種仍美） | 免費；推車可通行 |
| 10:15 | **大阪城天守閣** 外觀拍照 | 入場費待官網確認；內部多階梯，長輩幼童可不入內 |
| 10:45 | **御座船**（護城河遊船，約 20 分鐘） | 需抱嬰兒上船；票價待官網確認 |
| 11:30 | 沿大川河畔北行 → **造幣局「桜の通り抜け」**（步行約 20 分，或搭地鐵森ノ宮→谷町四丁目→天満橋，約 10 分） | ⚠️ **開放日期請出發前確認官方公告**；約 560m 單向步道，兩旁 140 種八重櫻 |
| 12:30 | 午餐：天満橋站周邊餐廳 | |
| 13:30 | 返回飯店午休（嬰兒＆幼童午睡） | |
| 16:00 | **黑門市場**（心齋橋步行 15 分或搭一站地鐵至日本橋站） | 平日下午人較少；推車可通行但略擠 |
| 18:00 | 晚餐：黑門市場或心齋橋周邊 | |

> 📝 **造幣局注意事項**：通道人潮擁擠，推車通行較困難 → 建議一人背嬰兒（背巾），推車可暫收折；長輩若腿力不佳可在入口處等候、於河畔長椅賞花。若造幣局未開放，改至 **大阪城西之丸庭園**（晚櫻品種）或 **毛馬櫻之宮公園**（大川沿岸）。

- 🌧️ **雨天**：御座船可能停航 → 改至 **大阪歷史博物館**（谷町四丁目站，室內）；造幣局通道雨天照常開放但地面濕滑，視雨勢決定。
- 😴 **累了**：省略造幣局或黑門市場，擇一即可。
