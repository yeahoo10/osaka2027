# 01-景點候選資料庫總覽（關西・京都・大阪・近郊）

> **受評團體條件**：6 名成人（含 68 歲長輩）＋ 2 名幼童（3 歲、5 歲）＋ 1 名嬰兒（0～1 歲，全天嬰兒推車）  
> **出遊期間**：**2027/2/24（週三）～ 2027/3/3（週三）**，共 8 天 7 夜  
> **氣候與季節特點**：冬末初春（約 3°C～13°C），早晚寒風強、室內均有暖氣；適逢**梅花祭滿開見頃**與**草莓甜度全年最高峰**。  
> **核心篩選準則**：推車無障礙（無長階梯／長陡坡）、室內避寒保暖、長輩步數控制、幼童放電互動。
