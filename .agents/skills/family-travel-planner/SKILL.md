# 家族旅行規劃與老小行程審查技能 (Family Travel Planner)

本技能融合了社群頂尖 Agent Skills（如 `ycyliu/travel-planner-skill` 的小紅書真實避坑與美學路書、`cody-hutson/travel-planner` 的多成員限制條件建模）以及真實三代同堂帶團實務經驗，專為「長輩 + 青壯年 + 嬰幼兒」的高複雜度旅行情境設計。

---

## 🎯 核心原則 (Core Philosophy)

1. **「一主一副」節奏律**：
   * 每天最多 **1 個核心大型景點** ＋ **1 個彈性備選點**。
   * 下午 13:30～16:00 預留「休整充電窗口」（長輩午休、幼童補眠或推車睡眠）。
2. **無障礙電梯優先（Accessibility First）**：
   * 雙推車或輪椅出行時，地鐵轉乘必須避開「只有階梯/手扶梯」的出口。
   * 日本老舊大站（如難波地下街、梅田迷宮、京都清水寺坂道）需特別標記無障礙直梯編號。
3. **低溫防風與體感防護**：
   * 港灣、戶外高處（如天保山、明石大橋、展望台露天區）風大，需搭配室內暖氣點調度。
   * 溫室（如草莓園、動植物王國）與室內主題館是冬季/雨天最佳避風港。
4. **全員需求分流兼顧**：
   * 不追求「隨時全員綁定」，善用「大商場/公園定點分流」（例如：媽媽採購嬰幼兒用品、爸爸顧幼童遊具、長輩在咖啡廳坐享點心）。

## 🧭 四大規劃與審核階段 (Workflow)

### 第一階段：成員限制與體能建模 (Persona & Constraint Profiling)
在規劃或審查行程時，優先盤點：
* **長輩成員**：膝蓋負荷耐受度（是否能爬階梯）、心血管耐寒程度、飲食偏好（需熟食、清淡、座位舒適度）。
* **嬰幼兒成員**：年齡、推車數量、午休頻率、泡奶熱水需求、尿布台與哺乳室需求。
* **行李與後勤**：大行李箱數量、安全座椅法規（日本 6 歲以下強制安全座椅）、隨行推車折疊體積。

### 第二階段：動線排雷與真實避坑 (Pitfall Verification)
針對每個排定景點進行「老小防雷審核」：
* ❌ **拒絕排隊超過 30 分鐘的未預約名店**：老小禁不起飢餓與低溫久站；正餐優先預約包廂或離峰用餐。
* ❌ **避開推車地獄石子路/高台階**：如伏見稻荷千本鳥居後段、清水寺三年坂二年坂石階、大阪城極樂橋階梯。
* ❌ **拒絕頻繁換飯店**：三代同堂建議「單一據點連住（如公寓式飯店 MIMARU 或市區包棟）」，省去每天打包 8~10 箱行李與老幼搬遷成本。
* ✅ **季節時令最佳化**：精準對齊產季與花期（如 2 月底大阪梅林滿開、草莓最高糖度期）。

### 第三階段：交通後勤與包車評估 (Logistics Optimization)
* **大行李移動日**（機場 ↔ 飯店）：全員超過 6 人且老幼同行時，一律優先採用「預約 10～14 人座 Hiace 包車接送」，直接飯店門口上下車。
* **郊區跨城日**（如往返京都郊區、堺市農場、奈良郊外）：優先評估一日包車，省去推車頻繁進出月台與電車轉乘等待。
* **市區遊覽日**：選搭「直達且雙向均有電梯」的地鐵線路，或分搭 2 部計程車短程接駁。

### 第四階段：輸出手機端離線互動路書 (Mobile Pocket Roadbook)
規劃完成後，將行程轉化為**單頁響應式 HTML 離線小手冊**，其格式規範如下：
1. **PWA / 手機瀏覽適配**：大按鈕、清晰時間軸、深色/高對比度文字，適合陽光下閱讀。
2. **一鍵導航直連**：每個景點與餐廳皆附上 `https://maps.google.com/?q=...` 連結，點擊直接喚起手機 Google Maps 導航。
3. **電梯出口指引**：明確標示「地鐵 X 號出口（電梯直達地面）」。
4. **離線緊急醫療卡**：包含救護車專線（日本 119）、多語言醫療諮詢電話、附近具備小兒科/急診之綜合醫院資訊。
5. **打包與隨身清單**：按「長輩藥品」、「幼兒副食品/備用衣物」、「推車防雨保暖罩」分類的互動 Checkbox。
6. **⚠️ 手機傳輸與開啟注意事項（重要防坑）**：
   * **不可直接依賴 LINE 內建點開**：手機版 LINE 點擊 `.html` 檔案時，會強制以純文字顯示原始碼或提示無法預覽，且 LINE 內建瀏覽器會閹割 LocalStorage 與外部 App 跳轉。
   * **正確本機開啟方式**：
     * iPhone：以 **AirDrop** 傳送，或從通訊軟體「儲存到檔案（Files）」，再以 **Safari** 開啟（可點選「加入主畫面」如 App 般使用）。
     * Android：下載至本機後，以 **Chrome** 瀏覽器開啟。
   * **最佳多人協作方案**：將單檔 HTML 部署至靜態託管（如 Vercel, Netlify, GitHub Pages），產生專屬 URL 網址直接傳送至 LINE 群組，全員點擊即開。

## 📋 行程快速檢核清單 (Quick Audit Checklist)

審核任何一份家族行程時，逐項檢查：
- [ ] **每日步行量**：成人步數是否控制在 10,000 步以內？推車路面是否平整無碎石？
- [ ] **洗手間與哺乳室**：主力景點是否具備無障礙多功能廁所與哺乳空間？
- [ ] **用餐備案**：當日午/晚餐是否已預約，或周邊有無需排隊的美食街備案？
- [ ] **雨天/寒流備案**：若當日氣溫驟降或下雨，是否有備用室內溫暖備案？
- [ ] **全員會合點**：若分散逛街，是否有清楚、好辨識的室內地標會合點？
