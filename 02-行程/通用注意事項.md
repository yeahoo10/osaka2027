# 通用注意事項（9人大家族出遊）

---

## 一、入境準備：Visit Japan Web

| 項目 | 說明 |
|------|------|
| 註冊 | 每位成人各自註冊帳號；幼童/嬰兒可登記於同行家族成員名下 |
| 填寫時機 | 出發前2週即可填寫，入境前6小時完成送出 |
| 必填項目 | 入境審查＋海關申報；免稅QR碼（如需要） |
| 注意 | 9人建議提前分工填寫，避免機場現場手忙腳亂 |
| 長輩協助 | 若長輩不熟悉手機操作，可由家人代為截圖QR碼備用 |

---

## 二、嬰兒推車與機場

| 項目 | 說明 |
|------|------|
| 推車托運 | 傳統航空：免費託運（不算行李件數）；廉航：需確認各家規定 |
| 登機口託運 | 多數航空允許推車推到登機口再交付，下機後於行李轉盤或登機口取回 |
| 關西機場 | 入境大廳可免費借用機場推車；往南海/JR月台有電梯 |
| 自備 vs 租借 | 建議自帶輕量摺疊推車（如 Cybex Libelle、Babyzen YOYO）；日本租借推車服務有限 |
| 備用 | 帶一條嬰兒背帶，人潮擁擠或階梯場景備用 |

---

## 三、包車與兒童座椅法規

| 項目 | 說明 |
|------|------|
| 日本法規 | 6歲以下兒童乘車**必須使用兒童安全座椅**（道路交通法第71條之3） |
| 適用本團 | 3歲＋5歲需兒童座椅；嬰兒需嬰兒提籃或後向座椅 |
| 包車安排 | 預約包車時務必告知：需2張兒童座椅＋1張嬰兒座椅，確認車型（9人需大型車） |
| 計程車 | 日本計程車法律上豁免兒童座椅規定，但**安全考量仍建議自備攜帶式座椅** |
| 公共交通 | 電車/巴士無需安全座椅 |

---

## 四、藥品・奶粉・尿布

| 項目 | 說明 |
|------|------|
| 常備藥 | 感冒藥、退燒藥（小兒專用）、腸胃藥、OK繃、體溫計、長輩慢性病處方藥（帶英文處方箋備查） |
| 奶粉/副食品 | 可自帶足量或於日本藥妝店/超市購買（明治、和光堂等當地品牌易取得） |
| 尿布 | 自帶1–2天份即可，日本各大藥妝店（松本清、大國藥妝）便宜齊全 |
| 濕紙巾 | 大量攜帶或當地購買 |
| 防蚊/防曬 | 4月開始需備（3月較不需要） |
| 入境限制 | 處方藥帶超過1個月用量需事先申請「藥監證明」（一般用量免申請） |

## 五、長輩健康注意

| 項目 | 說明 |
|------|------|
| 步行量 | 每日控制在1萬步以內；安排「長輩休息＋年輕人帶小孩」的分流時段 |
| 慢性病 | 攜帶足量處方藥＋英文診斷書；注意時差（服藥時間調整） |
| 膝蓋/腰部 | 避免過多階梯景點；善用電梯與手扶梯 |
| 飲食 | 注意生食過敏、鈉攝取量 |
| 緊急狀況 | 隨身攜帶健康狀況卡（中英日文對照） |

## 六、旅遊保險

| 項目 | 建議 |
|------|------|
| 保險類型 | 旅平險＋旅遊不便險＋海外醫療 |
| 長輩加保 | 68歲長輩建議加強海外醫療與緊急救援額度 |
| 嬰幼兒 | 確認保單涵蓋0歲嬰兒 |
| 班機延誤 | 不便險涵蓋行李延誤、班機取消（9人影響成本大） |
| 信用卡附贈 | 部分信用卡刷機票含旅平險，但額度通常不足，建議另外投保 |

## 八、IC 卡（交通卡）

| 項目 | 說明 |
|------|------|
| ICOCA | 關西地區主流IC卡；可搭電車、巴士、便利商店付款 |
| 現況 | 實體卡目前可能限量發售（**待官網確認當時販售狀況**）；可改用 iPhone/Apple Watch 的 ICOCA 或 SUICA |
| 幼童 | 6歲以下免費搭乘（不需IC卡）；5歲幼童免費 |
| 長輩 | IC卡儲值操作簡單，建議預存足夠金額減少排隊 |
